# IE3122 — Network Security

Study materials and quick-revision notes for the **IE3122 Network Security** module at the **Sri Lanka Institute of Information Technology (SLIIT)**.

This repository brings the lecture slides and their corresponding English–Sinhala revision notes together in one place. The notes are arranged for quick review before MCQs, structured questions, practical exercises, and examinations.

## Repository Contents

- Original lecture slide decks in PDF format
- Lecture-by-lecture quick-revision notes in Markdown
- English explanations with Sinhala summaries
- Exam-focused key points, examples, memory tips, and practice questions

## How to Use This Repository

1. Read the relevant PDF in the [`Lectures`](Lectures/) directory.
2. Review the matching Markdown notes using the lecture guide above.
3. Focus on definitions, attack mechanisms, security impact, and mitigation techniques.
4. Use the examples and practice questions for self-testing.
5. Return to the original slides whenever more context or a diagram is needed.

## Contributing

Corrections and useful additions are welcome. When contributing:

- Keep filenames and lecture numbering consistent.
- Verify technical content against the relevant lecture slides.
- Preserve important networking and security terminology in English.
- Keep Sinhala explanations simple and easy to revise.
- Do not include credentials, private lab data, or unauthorized attack instructions.

## Responsible Use

The security material in this repository is intended for academic study and authorized lab work only. Test security techniques only on systems and networks that you own or have explicit permission to assess.

## Disclaimer

These notes are supplementary revision material and are not a replacement for official lectures, module documentation, or lecturer guidance. Always confirm assessment requirements and technical details using the latest official course materials.
