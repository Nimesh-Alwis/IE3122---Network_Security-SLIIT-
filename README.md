# IE3122 — Network Security

Study materials and quick-revision notes for the **IE3122 Network Security** module at the **Sri Lanka Institute of Information Technology (SLIIT)**.

This repository brings the official lecture slides, lecture-by-lecture English–Sinhala revision notes, tutorial worksheets, lab guides, and compact final-exam reference sheets together in one place.

> **Final-exam notice:** The final examination is **2 hours** long, contains **4 structured essay questions**, and may assess content from **all lectures, tutorials, and labs**.

## Repository Contents

- Original lecture slide decks in PDF format
- Lecture-by-lecture quick-revision notes in Markdown
- Tutorial worksheets and practical lab guides in DOCX format
- Nine compact, print-ready final-exam reference sheets
- English explanations with Sinhala summaries
- Exam-focused comparisons, attack/defence matrices, Cisco commands, troubleshooting steps, and answer frameworks

## How to Use This Repository

1. Read the relevant official PDF in [`Lectures`](Lectures/).
2. Use the matching lecture Markdown file to revise the content in detail.
3. Complete the corresponding tutorial and lab from [`LABS and tutorials`](LABS%20and%20tutorials/).
4. Review the appropriate reference sheet for comparisons, commands, and condensed recall.
5. Practise four structured answers under a two-hour limit—approximately 30 minutes per question.
6. Use Sheet 08 to structure `describe`, `explain`, `compare`, `evaluate`, `recommend`, and `configure` answers.
7. Verify uncertain details against the official lecture, tutorial, or lab material.

### Recommended Revision Order

`Official slides → Detailed revision note → Tutorial questions → Lab mechanism/configuration → Topic reference sheet → Timed structured answer → Master last-minute sheet`

For attack questions, revise the full chain: **normal protocol behavior → vulnerability → attack mechanism → impact → mitigation → limitation → verification**.

## Contributing

Corrections and useful additions are welcome. When contributing:

- Keep filenames and lecture numbering consistent.
- Verify technical content against the relevant lecture slides.
- Check tutorial reasoning and Cisco commands against the corresponding DOCX guide.
- Preserve important networking and security terminology in English.
- Keep Sinhala explanations simple and easy to revise.
- Avoid repeating detailed content across multiple reference sheets; use cross-references instead.
- Do not include credentials, private lab data, or unauthorized attack instructions.
