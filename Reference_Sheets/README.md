## Design rules

- Detailed facts live in one main sheet; Sheet 09 uses short recall triggers and links instead of duplicating full explanations.
- Tables emphasize definition, mechanism, impact, mitigation, trade-off and verification—the reasoning requested by the tutorials.
- Cisco examples preserve the labs' Packet Tracer behavior while explicitly separating simulator limitations from production guidance.
- These sheets supplement, not replace, the official lecture slides, tutorials and labs.
