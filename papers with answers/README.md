- the full paper question text;
- simple English, mark-oriented answers;
- Cisco IOS command answers;
- ASCII diagrams for topology and attack-flow questions; and
- short technical cautions where a paper requirement is ambiguous.

## How to Use

1. Read one question from the original-paper section.
2. Write your own answer under timed conditions.
3. Compare it with the Simple English Answer Guide in the same file.
4. Check that each mark has a separate relevant point.
5. Practise Cisco commands and diagrams without looking at the guide.

> These are model revision answers, not an official marking scheme. Alternative technically correct answers may also receive marks.
